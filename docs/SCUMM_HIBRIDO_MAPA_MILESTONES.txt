======================================================================
POLITICA DE TIMING POR FRAME - CONTRATO ACTUAL
======================================================================

Los .BIN visuales pueden venir sin politica de velocidad runtime.
El MOTOR conserva el control del timing POR FRAME.

$4046             = indice de Frame actual
$4077             = timing global/default fallback
$4087-$40A6       = tabla runtime, 1 tick-count por Frame
$43A5             = ticks de Frame visible
$4067             = selector: timing[Frame]; si vale 0 usa fallback $4077

REGLAS:
- El timing runtime pertenece al MOTOR.
- Es POR FRAME, no un valor unico por Resource.
- Si timing[Frame] = 0, usar fallback global.
- No crear segundo scheduler ni segunda tabla.

BANCO UNICO / LIMPIEZA DE MEMORIA (BANK16)
======================================================================

OBJETIVO:
Dejar de buscar huecos por Resource y construir un banco unico y reutilizable
para cualquier ANIMACION.

CANDIDATO DE BANCO UNIVERSAL (AUN NO PROMOVIDO)
-----------------------------------------------
ANIMATION BANK  = $4400-$9FFF = 23.552 bytes
CHARSET STAGE   = $E800-$EFFF = 2.048 bytes

ES UN CANDIDATO, no un contrato final.

PRUEBAS BANK16
--------------
BANK16A = PASS
- backup temporal del charset de Resource01 movido de $9000-$97FF a $E800-$EFFF.
- libera $9000-$97FF durante CARGA 1.

BANK16B = FAIL
- KrillLoad extra a $8D00-$9FFF durante INTRO.
- cuelgue con luz de drive.

BANK16C = FAIL
- KrillLoad extra a $8D00-$8FFF durante INTRO.
- mismo patron de fallo.

BANK16D = FAIL
- probe post-INTRO a $8D00-$9FFF.
- CPU JAM.

BANK16E = FAIL
- probe post-INTRO a $8D00-$8FFF.
- CPU JAM / cuelgue.

BANK16F = PASS (ULTIMO PASS CONFIRMADO)
- SIN KrillLoad extra.
- despues de StopIntroA(), la CPU llena directamente $8D00-$8FFF.
- pipeline completo sigue PASS.

CONCLUSION BANK16F:
$8D00-$8FFF ES RAM reutilizable despues de la INTRO.
Los FAIL anteriores apuntan al KrillLoad extra / secuencia de I/O, no a la
invalidez del rango como RAM.

BANK16G = PENDIENTE
- CPU fill directo $8D00-$9FFF post-INTRO.
- sin KrillLoad extra.
- NO promover hasta PASS explicito.
