Contrato runtime ANIMATION_16F · V2E

Screen
Delta contra Frame N−1. El motor debe copiar primero la pantalla visible al buffer oculto (front→back) y recién después aplicar el decoder.
Presentación
Orden validado: screen swap → Color RAM. No apagar DEN y no usar N−2.

BITMAP_DELTA requiere el fast-path validado: un byte de bitmap $00 salta 8 celdas. Color RAM no está doble-buffered. Estas reglas quedan escritas en resource.json y ENGINE_V2E.txt.
